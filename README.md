# 우리 반 캐릭터 퍼레이드

동아리 발표회에서 쓰는 웹 자료입니다. 학생들이 각자 기기에서 그린 캐릭터가
선생님 화면(전자칠판·프로젝터)의 퍼레이드 무대에 실시간으로 나타나 행진합니다.

| 주소 | 쓰는 사람 | 하는 일 |
|---|---|---|
| `/우리반_캐릭터_퍼레이드.html` | 모두 | 첫 화면에서 "학생" / "선생님" 중 하나를 고름 |
| └ 학생 화면 | 학생 | 캐릭터를 그려서 퍼레이드로 보냄 |
| └ 선생님 화면 | 선생님 | 무대에 캐릭터를 띄우고 행진시킴 |

학생과 선생님이 **같은 주소**로 접속해야 서로 연결됩니다. 파일을 각자 내려받아
열면 데이터가 공유되지 않습니다.

## 파일

- `우리반_캐릭터_퍼레이드.html` — 프로그램 본체. 두 화면이 이 한 파일 안에 있습니다.
- `우리반_캐릭터_퍼레이드_안내서.md` — 수업 진행용 안내서 (화면 구성, 준비 절차, 주의사항)
- `firestore.rules` — 보안 규칙
- `firebase.json`, `.firebaserc` — Firebase 배포 설정
- `vercel.json` — 웹 배포 설정
- `캐릭터_퍼레이드.html` — 초기 단일 기기 버전. 한 대에서 그리기와 무대를 함께 보여 줍니다.
  발표회 당일에는 쓰지 않습니다.

## Firebase

이 발표회 전용 프로젝트 `brave-night-412309` 을 씁니다. 디지털 시민성 수업과
파이썬 첫걸음 채점기는 각각 별도의 프로젝트를 쓰므로 서로 영향이 없습니다.

HTML 안의 `firebaseConfig` 값은 공개되어도 안전한 "주소" 같은 값입니다.
비밀번호가 아니며, 실제 보안은 `firestore.rules` 가 담당합니다.

규칙을 고쳤다면 이 폴더에서 아래 한 줄로 올립니다.

```bash
firebase deploy --only firestore:rules
```

### 처음 설정할 때

Firebase 콘솔에서 **Authentication → Sign-in method → 익명(Anonymous)** 을
켜야 합니다. 학생이 로그인 없이 참여하는 구조라, 이걸 빠뜨리면 캐릭터 전송이
모두 실패합니다.

## 알아둘 점

선생님 화면의 "새 퍼레이드 시작(초기화)" 버튼은 참가 기록을 모두 지우며
되돌릴 수 없습니다. 이 수업에는 로그인이 없어서 규칙만으로는 누가 눌렀는지
가려낼 수 없습니다. 버튼 자체는 선생님 화면에만 있지만, 주소가 외부로 퍼지면
누구든 누를 수 있다는 점을 염두에 두세요.
